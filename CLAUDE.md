# CLAUDE.md

This project's agent instructions live in [`AGENTS.md`](./AGENTS.md) — read
that file first.

This file exists only because Claude Code looks for `CLAUDE.md` specifically.
By 2026, `AGENTS.md` is the convention most harnesses (Copilot, Cursor,
Claude Code, and others) have converged on for project-level context, so
that's where the real instructions live — one file to maintain instead of a
different one per tool. Keep this pointer file in sync if the harness you're
using still looks for its own filename.
